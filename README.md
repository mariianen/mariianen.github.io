# Portfólio — Mariane Ferreira Santos

Portfólio acadêmico com o estudo de caso Mega Compras, desenvolvido em três experiências práticas de Modelagem de Banco de Dados.

## Publicar no GitHub Pages

1. Na conta mariianen, crie um repositório público chamado `mariianen.github.io`. Se ele já existir, preserve seu conteúdo e avalie as alterações antes de substituir arquivos.
2. Envie `index.html`, `.nojekyll`, `README.md` e a pasta `assets` para a raiz do repositório. Não envie a pasta externa `portfolio` nem o ZIP inteiro.
3. Em **Settings → Pages**, escolha **Deploy from a branch**.
4. Selecione **main** e **/(root)** e clique em **Save**.
5. Acompanhe a publicação em **Actions**. Após concluir, o endereço esperado é https://mariianen.github.io/.

Documentação: https://docs.github.com/en/pages/quickstart
